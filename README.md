<h1 align="center">🎯 Sobre</h1>

<p align="center" style="font-size:20px;">
O <span style="font-weight: bold;">FreeMatch</span> é uma plataforma de relacionamentos moderna e inclusiva, criada para quebrar a barreira dos "paywalls" em encontros online. Aqui, o amor não tem preço: todas as funcionalidades são <span style="font-weight: bold;">100% gratuitas</span>.
</p>
